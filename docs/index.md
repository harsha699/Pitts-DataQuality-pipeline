# Pennsylvania Open Data Quality Pipeline

An open-source pipeline that profiles and cleans public datasets from the Western Pennsylvania Regional Data Center (WPRDC).

- [First Results & Methodology](results.md)
- [GitHub Repository](https://github.com/harsha699/Pitts-DataQuality-pipeline)

## Current Status
- Automated weekly runs via GitHub Actions
- First dataset: Allegheny County Employee Salaries (6,236 rows)
- Quality reports archived as GitHub Actions artifacts
